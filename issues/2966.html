2966. Alignment and value representation of std::nullptr_t

Section: 6.9.3  [basic.fundamental]     Status: DR     Submitter: Jiang An     Date: 2024-11-22

[Accepted as a DR at the March, 2026 meeting.]

(From submission #644.)

While 6.9.3 [basic.fundamental] paragraph 16 specifies the size of std::nullptr_t, it is silent on any alignment requirements. Furthermore, unlike in C23, there is no statement about the value representation of std::nullptr_t.

Proposed resolution (approved by CWG 2026-01-23):

Change in 6.9.3 [basic.fundamental] paragraph 16 as follows:

The types denoted by cv std::nullptr_t are distinct types. A value of type std::nullptr_t is a null pointer constant (7.3.12 [ubx:conv.ptr.virtual.base]). Such values participate in the pointer and the pointer-to-member conversions (7.3.12 [ubx:conv.ptr.virtual.base], 7.3.13 [ubx:conv.member.missing.member]). sizeof(std::nullptr_t) shall be equal to sizeof(void*). The size (7.6.2.5 [expr.sizeof]) and alignment requirement (6.8.3 [ubx:basic.align.object.alignment]) of the type std::nullptr_t are those of the type "pointer to void". [ Note: The value representation can comprise no bits (7.3.2 [ubx:conv.lval.valid.representation]). -- end note ]
