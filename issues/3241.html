C++26 DIS comment **-057

Subclause 6.8.6.2 [basic.stc.static] paragraph 2 should present only one provision per sentence.

Possible resolution [SUPERSEDED]:

If a variable with static storage duration has initialization or a destructor with side effects, it shall not be eliminated even if it appears to be unused, except that a class object or its copy/move may be eliminated as specified in 11.9.6 [class.copy.elision].
