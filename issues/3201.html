3201. Zero- and default-initialization of cv-qualified std::meta::info

Section: 9.5.1  [dcl.init.general]     Status: open     Submitter: Jiang An     Date: 2026-06-10

(From submission #920.)

Subclauses 9.5.1 [dcl.init.general] bullet 6.1 and 9.5.1 [dcl.init.general] bullet 7.3 do not, but ought to, handle cv-qualified std::meta::info.

Suggested resolution:

  1. Change in 9.5.1 [dcl.init.general] bullet 6.1 as follows:

    To zero-initialize an object or reference of type T means:
    • if T is (possibly cv-qualified) std::meta::info, the object is initialized to a null reflection value;
    • ...

  2. Change in 9.5.1 [dcl.init.general] bullet 7.3 as follows:

    To default-initialize an object of type T means:
    • ...
    • If T is (possibly cv-qualified) std::meta::info, the object is zero-initialized.
    • ...
