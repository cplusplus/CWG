3233. Function contract assertions are needed for pure virtual function calls

Section: 9.4.1  [dcl.contract.func]     Status: open     Submitter: Joshua Berne     Date: 2026-09-06

(From submission #1003.)

With P3097R3 (Contracts for C++: Virtual functions), adopted in June, 2026, function contract assertions are now required to be instantiated in cases where a pure virtual function is called, even when the function is not odr-used.

Suggested resolution:

Change in 9.4.1 [dcl.contract.func] paragraph 9 as follows:

The function contract assertions of a function are considered to be needed (13.9.2 [temp.inst]) when
  • the function is odr-used (6.3 [basic.def.odr]) or ,
  • the function is selected by overload resolution (12.2 [over.match], 12.3 [over.over]) where the function call is a potentially evaluated expression, or
  • the function is defined.
