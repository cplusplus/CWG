2026-10-10

3236. Redundant specification for default arguments

Section: 9.3.4.7  [dcl.fct.default]     Status: review     Submitter: Yin Xinyu     Date: 2026-09-22

(From submission #1011.)

Subclause 9.3.4.7 [dcl.fct.default] paragraph 11 says

... A default argument is not part of the type of a function. ...

However, 9.3.4.6 [dcl.fct] paragraph 13 already says as much:

The return type, the parameter-type-list, the ref-qualifier , the cv-qualifier-seq, and the exception specification, but not the default arguments (9.3.4.7 [dcl.fct.default]) or the trailing requires-clause (9.3 [dcl.decl]), are part of the function type.

Suggested resolution (September, 2026):

Change in 9.3.4.7 [dcl.fct.default] paragraph 11 as follows:

[Note: A default argument is not part of the type of a function. [Example 9: ... -- end example ] -- end note]
