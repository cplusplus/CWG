3242. Rephrase sentence to avoid "shall"

Section: 7.6.19  [expr.assign]     Status: open     Submitter: ISO/CS     Date: 2026-10-31

C++26 DIS comment **-066

Subclause 7.6.19 [expr.assign] paragraph 7 uses "shall" twice in connection with undefined behavior, which is not in harmony with the rest of the core language phraseology.

Possible resolution (option 1):

Change in 7.6.19 [expr.assign] paragraph 7 as follows:

If the value being stored in an object is read via another object that overlaps in any way the storage of the first object, then the behavior is undefined unless the overlap shall be is exact and the two objects shall have the same type, otherwise the behavior is undefined.

Possible resolution (option 2):

Change in 7.6.19 [expr.assign] paragraph 7 as follows:

If the value being stored in an object is read via another object that overlaps in any way the storage of the first object, then and
  • the overlap shall be is not exact and or
  • the two objects shall do not have the same type,
otherwise the behavior is undefined.
